# 章节标题翻译原则

把非中文书的章节标题翻译成中文 `cn_title` 时遵循的原则。**基调：现代汉语的雅，不是文言文**。听众是中文用户日常听书，太文绉/古文味反而显得疲惫。

> 这套原则来自 2026-04-26 与陈言对《The Technological Republic》22 章译名的两轮调试（v1 太机械、v2 太文绉、v3 适中确认通过）。

---

## ✅ DO

### 选词比白话上一档（不机械直译）

| 直译版 | 适中版 ✓ | 提升点 |
|---|---|---|
| 智能的火花 | 智能的**星火** | "星火"含燎原意 |
| 原子时代的终结 | 原子时代的**黄昏** | 挽歌感 |
| 心智的空心化 | 心智的**掏空** | 动作生动 |
| 审美的立场 | 审美的**视角** | 柔和不硬 |
| 赢家谬误 | 赢家的**迷思** | "迷思" = fallacy 现代汉语常见译法 |
| 迷失玩具城 | 玩具王国的**迷途** | "迷途"自然有意境 |

### 加"的"字让节奏自然

- **信仰的失守** > 信念失守
- **即兴的创业** > 即兴创业
- **失落的山谷** > 失落山谷

### 保留学术准确性

- `technological agnostics` → **技术不可知论者**（别图文学翻成"怀疑派"——agnostic 是哲学术语，准确性优先）
- `fallacy` 意指逻辑谬误时保留学术感，但中文里"迷思"也是合法译法（看上下文）

### 保留原文反讽引号

作者用 curly quotes（""）表反讽时（例：`"Flawed Systems"`），中文译名也带引号：
- ✓ `"残缺的系统"`
- ✗ `残缺的系统`（丢失反讽）

### 专有名词保留音译

人名 / 地名 / 机构名 / 自造词：
- `Eck Swarm` → **埃克蜂群**（"埃克"是人名 Dennis Eck 的音译，不要意译成"怪物群"）
- `Silicon Valley` → **硅谷**（约定俗成）

---

## ❌ DON'T

### 文言虚词当主结构

**之、乎、哉、何、以...为度** —— 一出现就显文绉绉。以下都是反例：

| ❌ 太文绉 | ✓ 适中 |
|---|---|
| 胜者**之**惑 | 赢家的迷思 |
| **以**美**为度** | 审美的视角 |
| 云**乎**？钟**乎**？ | 是云还是钟 |
| 智**之**星火 | 智能的星火 |
| 即兴**之**业 | 即兴的创业 |
| 群体**之**非 / 众人**之**非 | 群体的非议 |

### 单字硬凑（古意但信息少）

宁可多两个字保信息量、保自然，也别为了"凝练"砍成单字：

| ❌ 单字硬凑 | ✓ 自然现代 |
|---|---|
| 迷谷 | 失落的山谷 |
| 入漠 | 走向荒漠 |
| 千年之后 | 下一个千年 |
| 失谷 | 失落的山谷 |

### 古字替现代词

| ❌ 古字 | ✓ 现代 |
|---|---|
| **铸**一支好枪 | **造**一支更好的枪 |
| 残缺**之系** | 残缺**的系统** |
| 工程**之心** | 工程师**思维** |

### 武侠 / 古典味的词

- ❌ "工程师的**心法**"（武侠味）
- ❌ "残缺**之器**"（古器物）
- ❌ "**自序**"（书卷气过重，"序言"够了）

## Lift 度自检

每条译名翻完，问自己：和直译版相比 lift 了多少？

| Lift 度 | 例子 |
|---|---|
| **太低**（机械直译） | 赢家谬误 / 智能的火花 / 心智的空心化 |
| **适中 ✓** | 赢家的迷思 / 智能的星火 / 心智的掏空 |
| **太高**（文绉绉） | 胜者之惑 / 智之星火 / 心灵的蚀空 |

适中版应该："读起来不觉得在炫技、但比直译多一层意境"。

## 实操流程

1. 一次性把所有"未跳过"章节的 `title` 翻译成中文 `cn_title`
2. 写回 `.work/chapters.json`
3. 把翻译表给陈言过目（让他能纠正个别词）
4. 确认后才进步骤 5（生成音频 + 拼文件名）
